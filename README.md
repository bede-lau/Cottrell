<h1 align="center">Cottrell</h1>
<p align="center"><b>Turn electrode microscopy into traceable material intelligence.</b></p>

This repository is a pointer to the Cottrell project. Its application, research pipeline, screenshots and setup instructions live in the team repository:

### [Explore Cottrell →](https://github.com/Cottrell-LockedIn/AIxScience)

Cottrell investigates silicon/graphite battery electrodes using FIB-SEM microscopy, phase segmentation and batch comparison. It was built for the AI x Science Hackathon, Track 4 with Polaron.
